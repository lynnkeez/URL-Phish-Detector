The model

A Random Forest classifier trained on labelled URLs, using only features derived from the URL string itself — length, entropy, special-character counts, subdomain structure, suspicious keywords, and more. No page content is fetched and no external API is called, so a result is available in real time and works offline.

Why domain-aware splitting

Evaluation uses a grouped, stratified split (StratifiedGroupKFold) so that URLs sharing the same registrable domain never appear on both sides of the train/test split. A plain random split can let near-duplicate domains leak between train and test and inflate accuracy — this keeps the reported metrics honest.

Constraints this project works within

  • Time 11-week individual sprint timeline, so a shallow, fast-to-train architecture was chosen over deep learning.
  • Budget Zero budget — every tool in the stack is free and open-source.
  • Privacy URLs are processed in-memory only; nothing is logged or stored beyond the current session.
  • Technical URL-level features only — no JavaScript execution or full page rendering.

Success criteria

  • Accuracy ≥ 90% on the held-out test set.
  • F1-score ≥ 0.88 on the held-out test set.
  • Speed Classification and result returned within 2 seconds.
Built with Python, scikit-learn, and Flask — see the project's concept paper for full methodology.
