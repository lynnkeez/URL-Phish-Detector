The Model

A Random Forest classifier trained on labelled URLs, using only features derived from the URL string itself — length, entropy, special-character counts, subdomain structure, suspicious TLDs, and other lexical indicators. No network requests, no JavaScript execution, no page rendering.

Domain-Aware Evaluation

Evaluation uses a grouped, stratified split (StratifiedGroupKFold) so that URLs sharing the same registrable domain never appear on both sides of the train/test split. A plain random split can overestimate performance when similar domains exist in both sets.

Privacy First

URLs are processed in-memory only; nothing is logged or stored beyond the current session. No cookies tracking your checks, no external API calls, no analytics. Everything runs locally in your browser window.

Project Constraints

Time 11-week individual sprint timeline, so a shallow, fast-to-train architecture was chosen over deep learning.
Budget Zero budget — every tool in the stack is free and open-source (Python, scikit-learn, Flask).
Technical URL-level features only — no JavaScript execution or full page rendering to keep inference fast.

Success Criteria

Accuracy ≥ 90% on the held-out test set
F1-score ≥ 0.88 on the held-out test set
Speed Classification and result returned within 2 seconds

Built with Python, scikit-learn, and Flask — see the project's concept paper for full methodology and detailed feature engineering documentation.
